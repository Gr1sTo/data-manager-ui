# Data Manager UI

## Опис програми

**Тема магістерської роботи:**  
«Графічний інтерфейс користувача підсистеми керування сховищем даних програмного комплексу SmartEnergy».

**Data Manager UI** — вебінтерфейс для роботи з даними програмного комплексу SmartEnergy. Програма розроблена на React та призначена для взаємодії користувача з підсистемами зберігання реляційних, документоорієнтованих та файлових даних.

У поточній реалізації взаємодія з підсистемами здійснюється через REST API.

Для локальної розробки та тестування передбачено демонстраційний API (`mock-api`).

---

## Необхідне програмне забезпечення

Для локального розгортання проєкту необхідні:

- Windows 10/11 або Linux;
- Node.js;
- npm;
- Git;
- Docker / Docker Desktop — для контейнеризованого запуску Demo API;
- сучасний веббраузер.

Окрема СУБД для демонстраційної версії не потрібна. Тестові дані Demo API зберігаються у JSON-файлах.

## Встановлення

### 1. Клонування репозиторію

```bash
git clone <URL-репозиторію>
cd data-manager-ui
```

### 2. Встановлення залежностей

```bash
npm install
```

---

## Налаштування API

Адреси API задаються у файлі `.env`:

```env
VITE_RELATIONAL_API_URL=http://localhost:6023/api/relational
VITE_DOCUMENT_API_URL=http://localhost:6023/api/document
VITE_FILE_API_URL=http://localhost:6023/api/file
```

Для підключення інших API необхідно змінити відповідні адреси у файлі `.env`. Значення змінних використовуються у `src/api/config.js`.

Після зміни `.env` необхідно перезапустити застосунок.

---

## Локальний запуск

### Demo API

```bash
node mock-api/demo-server.js
```

Demo API запускається на порту `6023`.

### Графічний інтерфейс

В окремому терміналі:

```bash
npm run dev
```

Після запуску відкрити у браузері адресу, вказану середовищем розробки.

---

## Розгортання Demo API за допомогою Docker

Створення Docker-образу:

```bash
docker build -f mock-api/Dockerfile -t gr1sto/data-manager-ryzhenko-demo:latest .
```

Запуск контейнера:

```bash
docker run -p 6023:6023 gr1sto/data-manager-ryzhenko-demo:latest
```

Після запуску Demo API доступний через порт `6023`.
